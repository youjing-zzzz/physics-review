# Prompt #06 · 自信地错：一个真实反例逼出来的修复

- 日期：D4
- 触发：我随手拍了一张**《数值分析》目录**，让系统定位
- 关联 commit：`fix(locate): 加入绝对分与命中词数下限（AI #07）`

## 反例

输入：数值分析目录照片（OCR 后 162 字），内容是

```
2.1 二分法
2.1.1 二分法原理
2.2 不动点迭代法
2.3 牛顿迭代法
```

输出：

```
状态：confident
第2章 牛顿定律  分数=1.0  置信度=1.0
命中：牛顿×1
```

**以 100% 的置信度，把数学课的目录判成了物理第 2 章。**

## 根因

置信度只算"比例"：

```
confidence = 本章得分 / 所有章得分之和
```

全篇只命中一个词「牛顿」，其它章得分为 0，于是比例恰好 = 1.0。
阈值 0.45 完全挡不住——比例高不等于证据强。

这是**归一化陷阱**：分母退化时，比例会撒谎。

## 修复：三档判定 + 双下限

```python
MIN_SCORE = 3.0       # 绝对得分下限
MIN_KEYWORDS = 2      # 命中词数下限

if best.score < MIN_SCORE or len(best.hits) < MIN_KEYWORDS:
    status = "unknown"      # 证据不足，可能不是本课程
elif confidence >= 0.45:
    status = "confident"
else:
    status = "confirm"
```

## 回归验证（三条都要过）

| 输入 | 期望 | 实际 |
|---|---|---|
| 数值分析目录 | unknown | ✅ unknown「命中太少，可能不属于本课程」 |
| 物理扫描件单页 | confident 第 4 章 | ✅ 0.594，命中 力矩×6 等 5 个词 |
| 物理整卷 | confirm | ✅ 命中分散，三章接近 |

## 这个反例带来的架构结论

用户拍的**是目录**，而目录有天然的编号层级（`2.1`、`2.1.1`）。
所以主路径不该是"关键词指纹"，应该是**目录结构解析**：

```
正则抓 (\d+(\.\d+)*)\s*(标题) → 章节树 → 联网确认这是哪门课的哪一节
```

关键词指纹降级为**兜底**（图片没有编号时用）。
这样系统天然**科目无关**——用户拍物理、数学、数据结构都能用，
而不是只有物理能用。
