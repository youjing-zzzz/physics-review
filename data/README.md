# 数据目录约定

| 目录 | 放什么 | 是否进仓库 |
|---|---|---|
| `raw/textbook/` | 教材 PDF / 扫描件 | 否（版权） |
| `raw/exams/` | 历年真题 | 否（版权） |
| `raw/photos/` | 评测用的真实拍照样本 | 否（含个人信息） |
| `curriculum/` | 课程章节原始表（手工整理或解析产物） | 是 |
| `app.db` | SQLite 数据库 | 否 |

## 为什么 raw/ 不进仓库

教材和真题有版权，公开仓库里只放**解析后的结构化元数据**（章节名、页码、知识点名），不放原文。复现时由使用者自行准备 PDF。

## 评测样本

`raw/photos/` 里每张照片配一个同名 `.json`：

```json
{"file": "IMG_0123.jpg", "book": "大学物理（马文蔚 第七版）",
 "expected_chapter": "第5章", "expected_section": "5.3", "note": "荧光笔，有反光"}
```

D10 用这批样本算 top-1 / top-3 章节命中率。
